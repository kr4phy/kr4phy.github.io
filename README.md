# kr4phy.github.io

My smiple, lightweight portfolio website using picocss.
This website features the projects I’ve created so far and a brief introduction about myself.
I plan to add separate description pages for each project in the future. (Currently, only two projects have their own pages.)
Since it was built using only HTML and CSS (Picocss and custom CSS) and does not use JavaScript, the pages will display as intended even in browsers with strict security settings.


## Project structure
```
.
├── index.html
├── projects/
│   ├── index.html
│   └── ...
└── assets/
    └── main.css
```

## Development
1. Clone the repo:
   ```
   git clone https://github.com/kr4phy/kr4phy.github.io.git
   ```
2. Move to cloned repo and run http server:
   ```
   cd kr4phy.github.io/
   python3 -m http.server
   ```
